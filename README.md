## About Me

I build AI-powered products that turn machine learning research and modern AI capabilities into practical, usable systems.

My work spans **Agentic AI, Computer Vision, applied Machine Learning, and AI application engineering** — from multimodal interfaces and intelligent agents to ML systems with real-world deployment in mind. I care about the entire path from **idea → model → system → usable product**.

<tr>
<td width="50%" valign="top">

### 🧠 What I Build

- **AI Agents & Applications** — intelligent systems that reason, interact, automate workflows, and work with real-world data
- **Computer Vision Systems** — camera-based interaction, pose/face tracking, visual understanding, multimodal experiences
- **Applied Machine Learning** — predictive models, evaluation, explainability, production-oriented pipelines
- **AI Infrastructure & APIs** — integrating models into reliable applications via APIs, backend services, cloud deployment

<td width="50%" valign="top">

- **Reliable AI** — evaluating behavior, handling failure cases, designing around model limitations

- **Practical deployment** — performance, APIs, infrastructure, and production constraints from day one

#### [Omniq](https://github.com/yab-g4u/omniq) — Multimodal AI System
An AI system built around **voice-first interaction**, turning natural spoken conversations into structured workflows. Explores real-time voice interfaces, multilingual interaction, telephony-style experiences, and AI-driven information extraction.

`Agentic AI` `Voice AI` `WebSockets` `Multimodal AI` `Real-time Systems`

#### [Medscope](https://github.com/yab-g4u/medscope) — AI-Powered Health Intelligence
Makes medical and medication information easier to access and understand, through an AI-powered interface combining structured data with natural-language interaction.

`AI Applications` `NLP` `Information Retrieval` `Product Engineering`

#### [DataPilot](https://github.com/yab-g4u/DataPilot) — Explainable ML for Finance
An applied machine-learning system for financial risk analysis combining predictive modeling with **SHAP-based explainability** — built to make model decisions understandable, not just accurate.

`Machine Learning` `Explainable AI` `SHAP` `Scikit-learn` `FastAPI`

#### [Suno](https://github.com/yab-g4u) — Interactive AI & Computer Vision
A computer-vision-powered learning environment exploring how children can interact with technology through **facial movement, body tracking, gestures, speech, and visual feedback**.

`Computer Vision` `Pose Estimation` `Face Landmarks` `Multimodal Interaction`

#### [ATLAS](https://github.com/yab-g4u) — AI Portfolio Deployment
Turns a developer's professional information into a deployable personal website — exploring automated content generation, GitHub integration, and deployment workflows.

`Generative AI` `Automation` `Full-Stack AI` `Developer Tools`
